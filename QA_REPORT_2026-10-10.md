# NYX portfolio — graphical QA and review
**Date:** 2026-10-10
**Build under test:** Local static Next.js export in `D:\PORTFOLIO\nyx-portfolio\out`
**Rating:** **8.4/10** (editorial visual and interaction assessment, not a formal accessibility score)

## Scope and environment
Ran `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`, `pnpm verify:parity`, and a real headless **Google Chrome** walkthrough using `playwright-core` and the installed Chrome executable. The browser test served the actual built static export rather than the Next.js development server.

The browser walkthrough examined desktop **1440×900**, tablet **768×900**, mobile **390×844**, and small mobile **320×568**. Screenshots were reviewed for the desktop hero, featured work, projects, contact section, and mobile hero, featured work and contact section.

## Changes completed
- **LinkedIn:** Exact supplied profile URL added as the fifth social tile, with the recognizable LinkedIn icon and secure external link attributes.
- **Email:** No visible "Click to copy" label. The email address remains one click-to-copy control with an icon and a live accessible confirmation.
- **Carousel:** The manual Pause button is removed. The original continuous circular 3D carousel still pauses on hover and keyboard focus, resumes on mouse exit, preserves drag, previous/next selection, and reduced-motion behavior.
- **Responsive visual QA fixes:** A repository-card minimum-content width pushed 44px past the phone viewport. The related grid and long architecture text were corrected. The browser test then confirmed no page-level horizontal overflow on all four sizes.
- **Stylesheet integrity:** Restored the complete 65KB checked-in design system after an incomplete file operation; used targeted CSS edits to avoid truncation. This recovered the intended light editorial featured layout and project cover styling.
- **Readability:** Made the featured DataAutomated heading contrast sufficient against the light background and refined a forced line break in the AutomatedStructure cover.
- **Contact layout:** Five evenly distributed tiles at desktop, two-column adaptive arrangement at tablet/mobile, and one column at very narrow widths.

## Priority improvements before a 9+ score
1. Increase the size and contrast of the smallest captions, technical category labels and project metadata, particularly on phones.
2. Test the complete keyboard-only and screen-reader experience with assistive technology; current tests do not constitute a WCAG audit.
3. Measure performance on midrange mobile devices and slower networks. Automated image loading checks are not Core Web Vitals measurements.
4. Review project descriptions for concise first-glance summaries before the deepest engineering content.
5. Test actual deployed Vercel output separately from this local static export after pushing the commit.
